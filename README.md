# Innoloom — Complete HTML/CSS/JavaScript Prototype

This version is intentionally **frontend-only** for now. It uses HTML, CSS and JavaScript with `localStorage` so you can prototype the complete flow on your Mac without installing a backend yet.

## Includes
- Home page
- Login / signup
- Student and teacher roles
- Teacher dashboard
- Create class
- Assign students by email
- Student progress monitoring
- Course overview between Home and Module 1
- Persistent course slide menu
- Automatic progress tracker
- Module completion badges
- Module 1 WWW infographic + drag/drop assessment
- Module 2 web-server video simulation + MCQ
- Module 3 browser reading sections
- Module 4 website video simulation + two subtopics
- Module 5 HTML learning sequence + editable HTML preview + assessment
- Module 6 SDLC I DO / WE DO / YOU DO + assessment
- Course Summary
- Overall Assessment + final badge
- Downloadable study resources

## Run
You can open `index.html` directly in a browser. For a better local development experience, use VS Code with the Live Server extension and open the folder.

## Important
This is a prototype. Passwords and progress are stored in browser `localStorage`, so this is **not secure for real student use**. The later full-stack version should move auth, password hashing, class assignment, progress, assessments, badges and resources to a real backend/database.
